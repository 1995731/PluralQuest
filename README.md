# حكاية حبّة — قمح بلادي

تطبيق عربي تفاعلي للصف الثالث، مبني على صفحة درس «قمح بلادي» التي قدّمها المستخدم.

## التشغيل

تطبيق ثابت دون خدمات خلفية أو مفاتيح سرية أو خطوة بناء:

```sh
python3 -m http.server 8000 --directory .
```

يمكن نشر محتويات المستودع مباشرة عبر GitHub Pages. الصفحة الرئيسية هي `index.html`، ودرس الجموع السابق محفوظ في `plurals.html`.

## أنشطة التعلّم

- قراءة مشكولة في ثلاثة مقاطع مصوّرة، مع ثلاثة أحجام للنص.
- ست بطاقات مفردات تكشف معانيها وأمثلتها.
- ترتيب أربعة أحداث باستخدام أزرار تدعم لوحة المفاتيح.
- تشخيص بثلاثة أسئلة وتدريب بخمسة أسئلة من بنك يضم 19 سؤالًا.
- ثلاث مهارات: فهم المقروء، المفردات، وتسلسل الأحداث، بثلاثة مستويات.
- يزداد المستوى بعد نجاحين دون تلميح، ويبلغ التحدّي الأعلى بعد أربعة نجاحات من آخر خمس محاولات. تعيد محاولتان متتاليتان خاطئتان أو بمساعدة التدريب إلى المستوى الأساسي، مع عرض مراجعة مبسّطة. تُفضّل أسئلة المستوى المطلوب غير المعروضة في الجولة، ثم الأسئلة الأخرى عند نفادها.
- تقدّم محلي في المتصفح، وتنزيل تقرير JSON، وإعادة ضبط بعد تأكيد صريح.

## النص والصوت والصورة

الصوت لا يبدأ تلقائيًا؛ يمكن تشغيل كل مقطع أو سؤال وإيقافه، وتغيير سرعة قراءة المقاطع. يستخدم التطبيق Web Speech API وصوتًا عربيًا مثبّتًا على الجهاز. عند غياب الصوت يظهر توضيح وتبقى جميع الأنشطة متاحة بالنص. يُميّز إطار المقطع أثناء الاستماع. لا يوجد تسجيل لصوت الطالب أو تقييم آلي للنطق.

الرسوم القصصية توضيحية مولّدة لهذا المشروع، وليست صورًا من الكتاب. تُخزّن الصور محليًا بصيغة WebP مع نصوص بديلة. الواجهة تدعم RTL، لوحة المفاتيح، التركيز المرئي، وتقليل الحركة. لا تُرسل نتائج الطالب إلى خادم.

## التحقق

تم التحقق باستخدام Chromium وPlaywright من تحميل الصور، وإكمال التشخيص والتدريب، وانتقال المستوى صعودًا وهبوطًا، وحفظ النتائج بعد إعادة التحميل، وتكبير النص، وكشف معاني الكلمات، وترتيب الأحداث، وتنزيل التقرير وإعادة الضبط. فُحصت الصفحات الخمس بعرض 390 بكسل دون تجاوز أفقي. اختُبرت مسارات الصوت بمحاكاة وجود الصوت العربي وغيابه؛ يلزم جهاز بصوت عربي لاختبار جودة النطق الفعلية.

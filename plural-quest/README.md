# جزيرة الجموع — PluralQuest

تطبيق عربي تفاعلي تكيفي لدرس الجموع للصف الخامس، مع إنفوجرافيك قابل للطباعة.

افتح index.html في المتصفح، أو شغّل خادم ملفات ثابتًا في هذا المجلد. لا يحتاج إلى تثبيت حزم.

يتضمن تصنيف الجموع، تدريبًا داعمًا عند الخطأ، تحديًا ختاميًا، قراءة صوتية اختيارية بحسب دعم المتصفح، وحفظ آخر نتيجة محليًا.

## تحديث التصميم
ثلاث قصص قصيرة بكلمات قابلة للنقر وتسعة أسئلة مع تفسير فوري، وإنفوجرافيك ملوّن بثلاثة أعمدة ورسوم SVG، مناسب للطباعة الأفقية. ملفات التشغيل: index.html وapp.js وstories.js وtheme.css.

## أنشطة إضافية
لعبة سلال الكلمات بتسع كلمات، بطاقة إنجاز قابلة للطباعة، ورابط مستقل للإنفوجرافيك عبر `?view=info`، وتحميل الإنفوجرافيك كملف HTML مستقل يعمل دون اتصال.
